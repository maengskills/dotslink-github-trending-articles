[<img src="https://github.githubassets.com/favicons/favicon.svg" width="16" height="16" alt=""> nginx/nginx](https://github.com/nginx/nginx#readme)

**일간 7위** · 오늘 ★ +148 · 누적 ★ 33,659

브라우저에 이미지 주소를 넣으면 서버는 어느 폴더에서 파일을 찾을까요? NGINX(엔진엑스)는 주소에 적힌 경로를 읽어 해당 파일을 보내거나, 요청을 처리할 다른 서버로 넘겨주는 웹 서버입니다.

공식 입문 가이드에서는 한 사이트의 HTML 문서와 그림을 서로 다른 폴더에 넣습니다. 브라우저가 `/some/example.html`을 요청하면 NGINX는 `/data/www/some/example.html`을 찾습니다. 그런데 `/images/example.png`를 요청하면 경로가 달라집니다. 설정에 `/images/`로 시작하는 주소의 기준 폴더를 `/data`로 지정했기 때문입니다. 그림 자리에 404가 뜬다면, 이 예시에서 먼저 확인할 파일은 `/data/images/example.png`입니다. [NGINX 공식 입문 가이드의 정적 파일 예제](https://github.com/nginx/nginx.org/blob/HEAD/xml/en/docs/beginners_guide.xml#L253-L282)
