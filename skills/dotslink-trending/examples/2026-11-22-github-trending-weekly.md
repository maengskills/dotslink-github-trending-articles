Plannotator는 코딩 에이전트가 내놓은 계획과 코드 변경을 브라우저에서 검토하는 도구입니다. 문서의 문장이나 코드의 특정 줄을 골라 의견을 달면, 어느 부분을 어떻게 고쳐야 하는지 에이전트에 한꺼번에 보낼 수 있습니다.

가령 가입 화면 개편안에 ‘모든 사용자가 이메일을 다시 인증한다’고 적혀 있다면, ‘모든 사용자’를 선택해 ‘기존 회원은 제외해 주세요’라고 남기면 됩니다. 채팅창에서 어느 단계의 이야기인지 다시 설명할 필요가 없습니다.

![계획서에서 선택한 문장과 의견 입력창](https://raw.githubusercontent.com/backnotprop/plannotator/HEAD/.github/assets/annotate.webp)

*노란색으로 선택한 문장 아래에 의견 입력창이 열려 있고, 오른쪽에는 문서에 남긴 의견이 모여 있습니다.* [공식 문서 검토 예시](https://github.com/backnotprop/plannotator#readme)

이번 주 4위 Open Code Review가 이미 바뀐 코드에서 눈여겨볼 줄을 찾는다면, Plannotator가 빛나는 순간은 코드를 쓰기 전입니다. 가입 대상을 정한 사람과 화면을 구현할 사람이 같은 문장을 짚고 합의할 수 있다는 점에서 이번 호 대표로 골랐습니다.

공식 화면은 바로 볼 수 있습니다. 내 계획서로 써보려면 사용 중인 에이전트에 맞는 플러그인이나 연동 도구를 먼저 설정하세요. [내 에이전트의 설치 방법 보기](https://plannotator.ai/docs/)
